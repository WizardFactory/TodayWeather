# Bundled town search contract

- **AC1** A nonblank town query starts or joins a lazy load. The read and decode run outside the main actor. One successful result is reused across both screens and visits. A Google-only Start query does not access the loader. Edits, clearing, replacing the search word and visit replacement invalidate pending results without interrupting another consumer. Saved Places can show Google predictions while the local load is pending.
- **AC2** Preserve the 4,206 towns in order, their coordinates, UTF-16 substring matching, ten-result pages and cursors. Start keeps previous town matches on a valid miss. Saved Places clears them. Missing, unreadable or malformed data yields no new results and permits retry on the next local query. An empty array is a successful load. Preserve Google debounce, attribution and stale-response handling.
- **AC3** Compare baseline and candidate in Release on the same iPhone 16 simulator, with two batches of ten cold queries each. Retain raw samples and report decode, main-actor work and input-to-first-visible-result timings with median and spread. Use the matching first row as the endpoint and verify file I/O and decoding leave the input handler.
