# Specification: guarded web release
Consumes [intent](../intent/issue-2653.md). Configuration plus documentation; no app/backend contract changes.

Manual dispatch on master only, exact upstream repository; no tag/release/push automatic deployment. Dispatch selects a published non-prerelease webapp tag and immutable build artifact identity from its JSON release-manifest. Guard compares peeled tag SHA, full manifest SHA, successful `.github/workflows/web.yml` push on master in this repository, artifact run/id/digest/unexpired metadata, and extracted live/direct release.json. Revalidate after environment approval and before credentials. Never execute code from artifact or release source; checkout the dispatch workflow's trusted master SHA.

Required `webapp-production` environment has nonempty required reviewers, no self-review or admin bypass, selected master-only deployment branches. Operator configures it, enable flag, AWS OIDC role/account/region/destination/private versioned backup bucket separately. Missing guards abort; no long-lived keys. OIDC role excludes backend/store/infrastructure mutation and object deletion.

Before upload: AWS caller account, uploader preflight and runbook cache/certificate/DNS prerequisites, complete private backup of live object bytes/metadata/versions plus distribution configuration, inventory stability and durable completion marker. Publish no private inventory to Git/Actions artifacts. Upload unchanged candidate through existing uploader, obtain exact invalidation ID and wait, compare full live release SHA and run real live smoke. Upload public sanitized receipt/smoke even on failure. Receipt distinguishes pending/failed/deployed from Release publication; cancelled/no receipt requires operator reconciliation. No automatic rollback; operator uses private backup and existing runbook (including placeholder recovery worker) under separate approval.

Manifest schema version 1 includes target webapp, sourceCommit, buildRunId, artifactId, artifactDigest, rollbackReference (opaque operator inventory reference). Notes retain changes, operator, rollout evidence/status. Backend and Cordova naming explicitly includes host/platform. Backend decision covers drift, PM2/env, freshness/grid and AMI isolated validation/launch template/Spot/EIP guard, missing referenced guide prerequisite.

Verification: negative guard tests first (PR/main/manual/wrong SHA/expired/digest/unprotected environment), positive identity flow, backup failure prevents upload, uploader invalidation receipt/wait tests; YAML/actionlint and artifact policy; full existing web tests/typecheck/build; separate real CLI guard on local metadata and real build/dry-run with AWS unavailable, plus Archify artifact/browser/visual evidence. No live AWS writes.
