## Increment boundary

This core verifies 55 unique HTTP cases against independently converted grid/RSS/mid inputs across four phases (220 native responses). It excludes rich station/ASOS rows, air, life and image raw inputs. A subsequent stable task/branch/PR must add those inputs through real legacy conversion and canonical S3 publication, then repeat response and recovery checks. #2742 stays open. No complete domestic parity, production startup, EC2 latency, live quota, seven-day shadow or deployment rollback result is implied.

Functional headers are compared as an exact union. Only Date, Connection, Set-Cookie and the frozen baseline HTTP server header are declared transport differences; Content-Length is never ignored. The Undefined HEAD fix must produce an immediately terminating unknown-size empty stream, with GET, JSON HEAD and 304 wire framing preserved.
