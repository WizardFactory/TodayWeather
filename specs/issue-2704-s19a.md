# Contract
Accept a manifest with current and previous peer executable path, SHA256, revision and build profile. Reject missing artifacts, same revision/hash, hash mismatch, debug profile, unknown fields and non-full revision IDs before process startup.
Run three fresh native-only processes against one owned S3 peer. Inject only owned-loopback S3/geocoder/VC/WAQI roots through existing test example CLI; no legacy URL, no .env and no FCM/translation credentials. Both weather and geocode remain native in every phase.
First phase obtains recorded VC/air inputs; later phases must restore equal full functional response/header sets from S3 without weather-provider calls. Check cold+warm bodies and cross-phase conditional ETags. A KMA missing-data response is separately labeled partial, never full KMA parity. Notice empty state/read contract is separate from mutating notice recovery.
Bind report to actual binaries before and after every phase. A process error, mismatch, missing/extra response, unclean stop or unavailable artifact fails. Include actual phase timings, counts and limitations. Do not call old legacy/native coexistence rollback production-ready.
No application source/configuration/deadline/storage/schema change. No complete S19/production rollback claim.
