# Regional weather source register

- AC1. For each requested health and fire-risk product, record authority,
  geography, measurement / forecast / declaration, update or valid time,
  sample outcome and access/reuse condition.
- AC2. For each requested sunshine, terrain, rain or estuary product, record
  the same technical contract and the difference between representative data
  and unavailable products. Preserve units, times and vertical datum details
  when available. Attach a replay path or a concrete blocker.
