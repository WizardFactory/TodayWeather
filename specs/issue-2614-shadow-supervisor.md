# Bounded shadow supervision

Source: [accepted intent](../intent/issue-2614-shadow-supervisor.md), AK's seven-day scope and subsequent moderate shared-key waiver. This task connects the reviewed paired sampler to one temporary qualification host; production deployment and device delivery remain excluded.

- **BIND:** Pin artifacts and configuration; check the exact executable, process start identity and listener at launch, planned restart and at most 60-second intervals. No automatic restart or uncharged process generation. Stop acquisition on uncertain binding.
- **LIFETIME:** Journal run identity, request identity and original provisioning epoch before any mutation. Collection ends no later than that epoch plus 168 hours; cleanup reserve ends at 170 hours. Resume cannot reset either deadline. Reconcile an uncertain launch using the same client token and exact parameters; never provision a replacement host.
- **BUDGET:** Preserve 6,000 production GET/HEAD, one host, AWS $35 and paid API $5 ceilings. Stop acquisition at conservative projected $35 or accrued $28. Charge S3 physical attempts and PUT bytes before dispatch using one shared opt-in allowance per generation; durably consume disjoint generation allocations before launch (maximum three). Failed, cancelled and uncertain requests are not refunded. Candidate plus operator/export/cleanup must stay within 100,000 reads and 100,000 write/list calls. Reserve the final 1,000 operator reads and write/control attempts exclusively for cleanup; original-body export cannot spend this reserve. Keep ordinary runtime behavior unchanged when this opt-in is absent. Guard storage and disk independently. Treat four GiB as the host acquisition stop threshold, not the entire run's outbound ceiling. Price a conservative 48-GiB transfer reservation: four host, two original-body export, two paired evidence, eight control-response envelopes, and 32 protocol/termination contingency. Reserve control envelopes before calls, split four GiB ordinary and four GiB cleanup; exhaustion stops the affected work. This is a cost model, not a proof of physical network bytes or AWS billing enforcement. Sample the host every ten seconds, use a 30-second watchdog and ten-second service stop timeout; verify real Linux shutdown timing before launch. Unknown paid tariff means that provider cannot be enabled. Freeze per-runtime-unit prices and all three process grants in the manifest; price their sum at no more than $5 before reserving a generation. Shared keys, new UTC windows, failed installs and process restarts cannot replenish those grants.
- **SOURCE:** Export original versioned raw/catalog/product bytes with hashes within the evidence allowance. Nearby versions do not prove exact response dependencies. Missing source closure yields incomplete evidence, never qualification PASS.
- **CLEANUP:** Stop acquisition before export and exact-owned deletion. Distinguish successful empty results, explicit service absence, authorization failures, timeouts and malformed output. Only successful inventories and service-specific absence results establish deletion; errors remain unknown. Independently verify the exact instance, buckets, roles/profiles, security group and volumes.
- **PLACEMENT:** All implementation and tests belong under server2. Exact documentation exceptions are declared before edits. No legacy imports, production changes, automatic device sends or new accounts.

Verification uses isolated AWS fixtures, process/clock/crash fault injection and actual offline CLI scenarios. Every S3 physical send and shared transport allowance needs coverage before live enablement. Linux host guards and paid-provider policy must pass separately before launch; local state tests alone do not meet the complete contract.

Lowered candidate request grants to 90,000 each and operator requests to 10,000 each; the earlier four-GiB aggregate claim conflicted with separate exports and was removed. The public lifecycle supports one initial process only; unused future restart grants remain prepriced, and no restart command or automatic replacement is enabled. A stopped, missing or quota-limited family remains incomplete evidence.
