# Offline KMA compatibility specification
Revision 1; see ../intent/issue-2555.md.
Keep HTTP explicitly as the issue snapshot transport; migrate seven URLs to apis.data.go.kr. Accept `00` only; reject non-2xx/missing HTTP response, XML parse error, missing envelope/header/body, invalid or nonpositive integer count and empty/malformed item container through recvFail and callback error. Never print request URLs, keys, raw provider messages or parser/transport errors that can echo secrets.
Map PCP to r06 (mm), SNO to s06 (cm), TMP to t3h. Accept trimmed complete decimal numbers and category-specific mm/cm suffixes; explicit 강수없음/적설없음 become zero. Reject blanks, ranges, thresholds, unknown text, negative precipitation and nonfinite values to -1. TMP uses finite signed decimal and -50 sentinel. Retain legacy categories. RN1 accepts complete nonnegative decimal, optional mm and explicit no-rain; missing RN1 stays -1. No accumulation, scaling, period relabeling or consumer algorithm changes.
Preserve publication/date/time/grid grouping, current reh/lgt template sentinels and all unrelated source defaults. Document full disposition and operator-only policy.
Verification: real exported functions with pre-load stubs; XML fixtures are synthetic. Real XML parser plus event dispatch plus persistence/read adapter for additional offline smoke. Trace and characterize downstream time assumptions. No network, application startup or production configuration.
