# CI specification
Add .github/workflows/rss-offline.yml on push and pull_request. One ubuntu-latest job with Node22, TZ=UTC, read-only contents token, 10-minute timeout, default failing-step behavior. Checkout event ref (no privileged pull_request_target), do not persist token. Setup Node without package cache.
Run existing dependency-free regressions. Install pinned direct packages async2.5.0, express4.13.4, sprintf0.1.5, xml2js0.4.23 only under RUNNER_TEMP with lifecycle scripts disabled. Run all response scenarios using NODE_PATH and output dir under runner temp. No server install/start, credentials, live DB/provider calls, deployment or runtime-source edit. Network is needed only to fetch public actions/runtime/npm packages.
Expose commands and scope in offline README. No service architecture change; diagram not applicable. CI runtime configuration is tested before implementation and then by executing its actual shell commands. GitHub execution is observed after authorized branch push; do not equate local emulation with hosted job completion.
