# Acceptance for the first parity fixes

- **CURRENT-ROW:** with a publication covering the current slot, the current-time short row carries that publication's `pop`, `wav`, `s06`, `r06`, `tmn`/`tmx` (where legacy keeps them) and the observed fields; with only the previous publication covering it (HH+2:10 to HH+2:59), the previous one supplies them, read from S3 or fetched once per cell and three hours. The row marked `currentIndex` (it follows the observation time, e.g. the 06:00 row at 09:10 with an 08:50 observation) keeps its forecast the same way, and the publication covering it is read or fetched once per cell and publication. Past rows are unchanged otherwise.
  Tests (domestic): `observed_history::the_current_row_keeps_its_forecast_under_asos_primary`, `observed_history::the_row_marked_current_keeps_its_forecast_when_the_observation_lags`, `observed_history::a_past_row_keeps_no_forecast_total_behind_its_cleared_amounts`, `parity_evidence::the_current_row_of_the_parity_run_keeps_its_forecast`, `parity_evidence::the_current_row_keeps_its_forecast_extreme_where_legacy_does`, `shown_publication::the_row_shown_as_current_gets_the_publication_covering_it`, `shown_publication::a_fresh_observation_needs_no_older_publication`. Tests (library): `source::required::tests::the_previous_short_publication_is_required_only_while_the_latest_misses_the_current_slot`, `source::previous_short_tests::the_previous_publication_supplies_the_current_slot_after_the_latest_moves_on`, `source::previous_short_tests::a_latest_publication_covering_the_current_slot_needs_no_other`.
- **SENTINELS:** a missing `s06` is -1 after the unit conversion; a missing `pop` is 0 as in legacy `adjustShort`; ASOS-filled `uuu`/`vvv` are -100 when missing.
  Tests: `present::tests::a_missing_snow_amount_stays_missing_through_the_cm_to_mm_conversion` (library), `observed_history::a_missing_probability_reaches_the_client_as_legacy_sends_it`, `observed_history::asos_filled_hours_keep_the_missing_wind_component_value` (domestic).
- **YESTERDAY:** live station X now and ASOS station X exactly 24 h earlier give `comparisonAvailable` true with `t1h`; different stations, other hours and other sources keep the safeguard; a stored grid yesterday row still wins.
  Tests: `policy::tests::the_parity_run_pairs_compare_with_yesterday`, `policy::tests::the_comparison_safeguard_still_withholds_unrelated_pairs` (library), `observed_history::a_live_reading_compares_with_the_same_stations_asos_hour_a_day_earlier`, `observed_history::another_stations_asos_hour_keeps_the_comparison_safeguard`, `parity_evidence::the_parity_run_places_get_yesterdays_temperature` (domestic).
- **PLACEMENT:** the placement gate passes against `server2/config/tasks/KMA-RESPONSE-PARITY.json`, and the artifact policy passes on outgoing commits.
  Checks: `tools/check_placement.py --root .. --declaration config/tasks/KMA-RESPONSE-PARITY.json --base origin/master` (from `server2/`), `scripts/check-artifact-policy.py`.

Failure paths: no publication covers the current slot and the fetch fails: the row keeps legacy's values for a missing publication (pop 0), never an error; a yesterday row without a station id keeps the safeguard.
Tests: `observed_history::without_a_covering_publication_the_current_row_keeps_legacys_missing_values` (domestic), `source::previous_short_tests::a_failed_previous_publication_is_not_requested_again_for_three_hours` (library), and the station-less case in `policy::tests::the_comparison_safeguard_still_withholds_unrelated_pairs`.
