# Acceptance for client validation

Tests are in `server2/tools/verification/test_kma_client_validation.py`.

- **CAPTURE:** `kma_client_validation.py capture` sends one GET with `Accept-Language: ko-KR,ko;q=0.9`, with no retry and no redirect, and writes the body as received and a metadata file (URL, UTC send time, status, duration, size, `date`, `age`, `x-cache`, `cache-control`, `x-amz-cf-pop`). Only HTTP 200 with a JSON object body exits 0; a non-200, non-JSON or failed answer exits 1 and is still recorded. Checked against a loopback HTTP server; tests never reach production. Checked by `CaptureTest`: `test_capture_writes_the_body_and_metadata_of_one_get`, `test_capture_without_a_label_names_both_files_after_the_path`, `test_error_answers_are_recorded_with_exit_one_and_no_second_request`, `test_a_refused_connection_is_recorded_with_exit_one`.
- **COMPARE:** `kma_client_validation.py compare --reference <file> --candidate <file>` matches `short` and `shortest` rows by `date` and `time`, `midData.dailyData` rows by `date`, other object arrays by index and objects by key; rows and fields only the candidate has are allowed. It lists every reference row the candidate lacks, every reference field the candidate lacks, and every value that is valid in the reference and invalid in the candidate (absent, null, an empty string or scalar list where the reference is not empty, the temperature sentinel at or below -50, or a negative number in a field that is never negative, which is every numeric field except the temperatures, `uuu`, `vvv` and `fromToday`). A reference value that is itself invalid requires nothing of the candidate. Valid values that differ are information only. It exits 0 with nothing missing, 1 with missing data, and 2 when the bodies are not comparable (different `currentPubDate`, `shortestPubDate`, `shortPubDate`, `midData.landPubDate` or `midData.tempPubDate`, not a KMA body, or unreadable); the lists are written in every case. Checked by `CompareTest`: `test_identical_bodies_pass`, `test_missing_field_is_reported_by_path`, `test_missing_rows_are_reported_once_by_key`, `test_rows_match_by_key_and_extra_candidate_rows_pass`, `test_other_object_arrays_match_by_index`, `test_sentinels_null_and_empty_values_against_valid_reference_values_are_reported`, `test_both_invalid_is_not_reported`, `test_signed_fields_may_be_negative`, `test_valid_value_differences_are_information`, `test_different_publications_are_not_comparable_but_lists_are_written`, `test_non_kma_or_unreadable_input_is_not_comparable`; and by `RecordedBodiesTest` on the recorded legacy bodies: `test_every_recorded_kma_body_passes_against_itself`, `test_rows_and_fields_removed_from_a_recorded_body_are_reported`.
- **EXCLUDED:** the parts named in the intent are never counted as missing and are listed under their own key. Fields only the candidate has (for example `forecastNarrative`, `freezeGrade`) are allowed. Attribution and `historyStatus` gap lists are not judged; a label or grade is judged only when its value field is equal, and otherwise listed as value-dependent when the candidate lacks it. Checked by `CompareTest`: `test_exclusions_are_listed_but_never_missing`, `test_attribution_and_history_gap_lists_are_not_judged`, `test_candidate_only_keys_pass`, `test_label_is_judged_when_its_value_field_is_equal`, `test_label_follows_a_differing_or_absent_value_field`.
- **DOCUMENTS:** `docs/architecture/mobile-api.md`, `docs/architecture/server2-kma-data-design.md` and `docs/evidence/research/kma-speed-options-2026-11-04.md` describe the two tools as above; dated evidence keeps its original text with a dated note. `docs/architecture/server2.md` has no section on KMA verification tools and stays unchanged.
- **PLACEMENT:** the placement gate passes against `server2/config/tasks/KMA-CLIENT-VALIDATION.json`, and the artifact policy passes on outgoing commits. `server2/tools/ci.py` runs the tests; its `run_isolated.py 'test_*.py'` selection discovers only `server2/deploy/benchmark`.

Failure paths: a reference that is not a KMA body, an HTTP error capture or an unreadable file is not comparable (exit 2). A candidate row present with every field but invalid values is reported per value, not as a missing row.
