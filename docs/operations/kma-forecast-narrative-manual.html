2. Interpret time and text

17:00 KST is 08:00 UTC. Keep newline characters. The server escapes HTML metacharacters for the existing HTML binding; do not unescape them. The encoded image tag in the excerpt is inert provider text.

3. Missing or expired narrative

Type5 is omitted when its publication is 24hours old, invalid or unavailable. Warning types1–4 keep their existing behavior. Cache freshness is shortened near expiry. A failed acquisition never re-dates stored content.

Local smoke also verified repeat/new publications, bounded quota exhaustion, warning preservation and exact24h expiry. No live provider, mobile build, deployment or production readback is claimed. See the operator runbook for approved rollout and rollback.
