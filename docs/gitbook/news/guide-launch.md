# Introducing the TodayWeather User Guide

You can now look up one TodayWeather task at a time. To check the weather in another neighborhood, start with [Add a location on Android](../guide/android-add-place.md). It shows how to find the right search result and check that the place was saved.

You can also [compare today's temperature with yesterday's](../guide/hourly.md) or [set a weather alarm](../guide/alarms.md). If you're using a browser, start with [Find, save and share a location on the web](../guide/web-places.md).
