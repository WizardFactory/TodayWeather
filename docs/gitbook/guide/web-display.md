# Change text size, language and the web start screen

Open **Settings** and set **Appearance** to System, Light or Dark. Set **Current weather background** separately. If you prefer a still background, turn off **Background motion**.

To enlarge the chart and numbers, set **Text size** to 130% and return to the weather screen. If you use a keyboard, press Esc to close the navigation menu.

**Language** initially follows your browser. Place names and some bulletins may stay in the data provider's language after you change it. You can also change **Units and air quality standard**, **Start screen** and **Auto refresh**. These preferences are saved in this browser. If browser storage is unavailable, they last for the current visit.
