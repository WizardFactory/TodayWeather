# User Guide

The app guides use Android screens. For iPhone tracking permissions or the web version, choose the relevant topic below. Some illustrations show the Korean interface.

- [Getting started and managing locations](places.md) — Choose your first location and manage the places you follow.
- [Weather and air quality](forecast.md) — Read forecasts, pollen risk, station readings and national maps.
- [Alerts and app settings](preferences.md) — Manage notifications, appearance, privacy and common problems.
- [Using TodayWeather in a browser](browser.md) — Save locations, read charts, back up your settings and use stored weather offline.
