# Find web notification, pricing and support information

For scheduled alerts, use the [mobile app's weather alarm settings](alarms.md). The browser notification screen offers instructions for the mobile app.

Open **Settings → About the service** for **Privacy and data**, **Pricing and app purchases** or **Report a problem**. You can use the web version without paying. Places and purchases from the mobile app do not transfer automatically to the browser.

**Report a problem** opens the public GitHub issue list. Include the symptoms and browser version if you report a problem. Leave out your exact location and other personal details.

To find the data source, open **Help** or check the provider credit on the weather and air quality cards. The source can vary by location and data type. **Open external wind map** takes you to a separate map service.
