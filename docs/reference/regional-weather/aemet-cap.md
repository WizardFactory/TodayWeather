# Direct AEMET CAP data

The official Spain Atom index offers the full current CAP state as its first archive. On 2026-11-21, the public snapshot at 10:14:23 UTC and authenticated OpenData `esp` held 243 byte-identical messages by CAP identity, including 207 Alerts and 36 Updates. The HTTP transports used gzip tar and plain tar respectively. The public snapshot is the runtime source. [Official Atom documentation](https://www.aemet.es/es/rss_info/avisos/esp) · [OpenData specification](https://opendata.aemet.es/AEMET_OpenData_specification.json)

The v6 AEMET warning zones, including 182 land and 51 coastal zones, use EPSG:32630 in the official ZIP. To regenerate the compressed asset, use `python3 scripts/convert-aemet-warning-zones.py archive.zip server/lib/warnings/data/aemet-zones-v6.json.gz` with `pyshp`, `pyproj` and `shapely`. The script checks the upstream archive digest and transforms coordinates to WGS84 longitude and latitude, preserving polygon interiors and multipolygons. Land takes precedence where the official coast layer overlaps land. [Official ZIP and bundled attribution](https://www.aemet.es/documentos/es/eltiempo/prediccion/avisos/plan_meteoalerta/AEMET-meteoalerta-delimitacion-zonas.zip)

The CAP adapter verifies every asset code is represented in the official national archive, rejects any unknown codes, and handles references before expiration or point filtering. The source lease cannot outlive the zone’s last confirmed CAP expiry, including Minor coverage. A publisher stuck on an expired archive yields unavailable coverage. The issuer uses a terminal Update expiring at its sent time to end referenced warnings. CAP Minor represents no warning. Yellow, orange and red correspond to Moderate, Severe and Extreme. [AEMET CAP profile](https://www.aemet.es/documentos/es/eltiempo/prediccion/avisos/plan_meteoalerta/METEOALERTA_ANX3_CAP.pdf)

For rollout qualification, enable the flag on an isolated server1 process. Exercise Madrid, Barcelona, a foreign point, and a provider failure. Check `current` and the returned array separately, inspect per-worker upstream request counts and confirm Gateway forwards the warnings path without caching it. Set `AEMET_WARNINGS_ENABLED=false` and restart the service to roll back. Existing weather and KMA requests remain separately served.
