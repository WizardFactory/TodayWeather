# Production PWA adoption plan

Owner: root Codex. Date: 2026-10-01. Scope: [#2649](https://github.com/WizardFactory/TodayWeather/issues/2649), [intent](../intent/pwa-design-adoption.md) and [contract](../specs/pwa-design-adoption.md). #2650 remains outside this workspace. Endpoint: verified pre-merge; no merge, queue or deployment.

## Implementation and verification

1. Record intended failing tests for display migration/rollback, full daily history and numeric wind direction before implementation. Preserve units and precipitation basis.
2. Extend the shared token generator into ignored web outputs and lifecycle hooks. Ship the hashed Pretendard font and OFL license. Generate the external prepaint script from canonical colors.
3. Implement separate display preferences, validated migration, legacy dual-write, OS appearance synchronization and backup/clear handling.
4. Derive typed hourly/daily chart models from existing normalized data. Render full timelines, current/yesterday points, shared daily scale, keyboard cursors, equivalent tables and a persisted wind/humidity expander.
5. Apply type, color, space, radius, elevation and layer tokens. Preserve weather route/navigation behavior with the hero/hourly/daily/air/details order. Add native confirmation, skeletons, semantic controls and condition-driven skies. Remove unused CSS.
6. After green unit/type checks and refactoring, run an additional real static-browser smoke with blocked live requests. Verify Chromium/WebKit, seven languages, light/dark, root factors 1/1.5/2, exact input tiers, narrow charts, 90% floors, 130% persistence, accessibility and selected screenshots. Compare physical iOS separately and restore device settings. Retry physical Android; if unauthorized persists, use the AK-authorized isolated Android emulator fallback at 1.0/1.3 and record emulator/runtime/APK provenance.
7. Update specifications, architecture, diagrams and the user manual with actual scenario screenshots, editable source and a visually checked PDF. Preserve dated historical evidence as historical.
8. Clean retained artifacts and run the repository checker on staged/outgoing content. Commit/push the scoped PR, observe CI and conduct independent PR review under the 2026-10-01 fallback chain. Keep stable findings and author responses. Stop unmerged with current readiness evidence.

## User scenarios and coverage

| ID | User and goal | Prerequisites / ordered actions | Expected result and failure path | Criteria / evidence |
|---|---|---|---|---|
| S1 | Returning user: preserve display preferences across an upgrade or rollback | Existing legacy theme. Open settings; choose system appearance and plain background; set 130%; reload; let an old build rewrite generic settings | Separate display values survive; legacy theme remains valid. Corrupt fields fall back individually; unavailable storage keeps choices in memory and reports failure | AC8, AC12, AC18; display unit tests and `pwa-design.spec.ts`; manual Display |
| S2 | Weather reader: compare today, yesterday and upcoming changes | Existing location and API weather. Open weather; scroll the hourly plot; use arrows/Home/End; expand wind/humidity; open the data table | Full rows, aligned yesterday/current point, no null bridging, consistent units and data table. Missing values use a dash and no fabricated point | AC6, AC7, AC15; core chart tests, chart browser tests; manual Hourly |
| S3 | Weather reader: compare daily minima/maxima and history | Supplied daily rows. Continue below hourly; compare past/today/future bars; move cursor; open table | Shared vertical scale, cool minimum/warm maximum, current marker within domain, past probabilities hidden, matching AM/PM icons merged. Missing extrema omit a bar | AC6, AC7, AC14; daily core/browser checks; manual Daily |
| S4 | Air reader: inspect pollutant data without relying on color | City air data. Open air; choose a pollutant with radio arrows; scroll forecast; open data table | Grade text and legacy hues remain legible; keyboard/table show the same data. Missing life-index or city air data is explicitly absent; no substitute measurements | AC2, AC10, AC16; air/browser regression and axe; manual Air |
| S5 | Phone or tablet reader: increase readability | Supported browser. Select language and text size; compare light/dark; use menu/settings at narrow or enlarged sizes | Input-tier body sizes and role floors remain readable; only plots/tables scroll; no clipped translated labels. Motion is opt-in and disabled by reduced motion | AC4, AC5, AC6, AC11, AC12, AC13; language/tier matrix and separate physical iOS / authorized Android emulator comparison; manual Display |
| S6 | User: cancel destructive browser data deletion | Saved places/display. Open settings; request deletion; cancel or Escape; request again and confirm | Cancel preserves all data and restores focus; confirmation resets preferences/display/snapshots. Import cancellation also preserves existing data | AC8, AC10, AC17; native-dialog regression; manual Data |
| S7 | Maintainer: reproduce the same consumer from a clean checkout | Locked dependencies and approved shared tokens. Install; typecheck; test; build; generate twice; inspect assets/docs | Byte-identical generated outputs, shared tokens and hashed licensed font; no forbidden colors/px fonts/dead selectors. Missing tool/device access is recorded as not run | AC1, AC2, AC3, AC9, AC17, AC18; clean-install, generator/source tests and documentation assessment |

These scenarios drive test and manual coverage. Browser root enlargement is not physical Dynamic Type or pinch zoom. Native system scaling is enabled only after the D3 comparison supports it; D2 and browser text size remain the default strategy.
