# Rewrite reference gap review (2026-09-24)

Scope: the merged [rewrite reference package](../../docs/rewrite/README.md) was audited against its four original requirements: (1) screenshots and a definition for each main screen, (2) client input formats and processing, (3) server per-request assembly order and diagrams, (4) other references useful for a server/client rewrite. Source baseline stays `ff7acf3996ccb66c912d2ed4710cf300197d6966`; `client/`, `server/`, `tw.ios/`, `ta.ios/` and `applewatch/` were not modified. Work ran 2026-09-24 to 2026-09-25, including a final round on 2026-09-25 whose critic gaps FIN-1 to FIN-4 are [below](#final-round-fin-1-to-fin-4). Process, checks and limits are in the [verification record](README.md#2026-09-24-gap-review) and its [final-round section](README.md#2026-09-25-final-round).

**Re-baseline note (2026-09-25).** The package now targets `bd6640f2` ([re-baseline record](README.md#2026-09-25-re-baseline)). This table stays the record of the gap review at `ff7acf39`: its gap IDs, verdicts and "now addressed" locations are unchanged, and the documents it links were re-verified by their owners. Upstream changes touched these rows: SRV-2 (A29 item 10 resolved in `2116c6bf`), SRV-6 (direct APNs removed in `45b2eb3f`), RR-01 (the Web PWA added as a consumer; route counts unchanged), RR-02 (the Web PWA is described in native consumers §5), RR-03 (two native ASOS collections; mid RSS collections dead), RR-04 (KMA endpoints migrated, mid RSS retired, ASOS provider added), RR-05 (New Relic and APN names removed, four `ASOS_HISTORY_*` names added) and RR-08 (New Relic and APNs removed from the secret and sink tables). **Verdicts** come from five adversarial verifiers (two for server assembly): *confirmed* (the gap exists as reported), *partially* (the gap exists but the verifier narrowed or corrected the auditor's claim; the corrected facts were applied) and *added* (a gap the verifier found that the auditors missed). Severity is the verifier's. "Not addressed" lists parts deliberately left out or still open; nothing in this table claims runtime verification unless the addressing document labels it synthetic execution, probe or capture.
