# Test design
All fixtures synthetic. AC1: seven exact URL builders and organizer dispatches; controlled errors for HTTP/XML/envelope/header/count/items. AC2: publication/grid/date/time, PCP/SNO no-value/numeric/unit/unsupported text, TMP finite signed values, legacy categories and shortest RN1 including zero and missing input. AC3: source assertions for preserved manager/Kakao/policy plus behavioral logger, current merge and request-index boundaries. AC4: captured logs exclude dummy key/URL; deny unstubbed dependencies and timers. AC5: storage read-through and legacy consumer characterization establish field continuity, never period equivalence. AC6: evidence and handoff document checks.
Prerequisites: Node v22.22.2; isolated Mocha 2.5.3, xml2js 0.4.23, async 2.6.4. Source modules evaluated through explicit whitelist; real XML and async library, fake HTTP/log/model/timer boundaries installed before evaluation. No application/config import.
Smoke scenario: build synthetic XML, call actual requestData with synthetic HTTP callback, feed actual event result into actual saveShort/getShortFromDB using an in-memory model, verify pubDate, grid, dates and exact values. Repeat invalid response and assert failed result and zero writes. This is real local module integration, not live HTTP or Mongo. Separate executable and evidence from unit tests. Cleanup is in-memory; dependencies confined to /tmp.
