# Separate parity denominators

`oracle.json.gz` contains98 synthetic dependency-boundary recordings. They remain
verified by `parity.rs`; they are not represented as canonical S3 acquisitions by
this task. DB1 documents, injected database errors and JavaScript coercion-only
values cannot be promoted to provider raw by inventing a record. Other original
cases have no complete original provider corpus, even where their behavior is
representable. `kma-replay.json` retains every original ID and its reason.

`s3-response.json.gz` is a new independent Node16 collector/saver/HTTP recording
from shared raw acquisitions. Its unique case count, HTTP methods/locales/units,
and four restart/disk phases are separate from the98 assembly scenarios. Do not
add these counts together as whole-response S3 coverage. Fields not supplied by
this canonical corpus are explicitly documented as absent; baseline boundary
answers must follow legacy's missing-data behavior, not desired native output.
